# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone who takes part is expected to follow it.

In short: be respectful, assume good intent, and keep criticism about the work. Harassment and personal attacks are not accepted.

## Report a problem

Report conduct problems privately to the maintainer through [GitHub's private reporting form](https://github.com/jcvargasGit/hatstand/security/advisories/new). Start the title with `Conduct:`. Reports stay private, and the maintainer decides on a response according to the Contributor Covenant's enforcement guidelines.
